Database installeren

Voor de beheerder van de kinderkerk-app. Open Supabase in een tweede tabblad en volg de stappen. Met de knoppen kopieer je alles; daarna plak je het in Supabase.

1 Database inrichten

  1. Ga in Supabase naar SQL Editor en tik op + / New query.
  2. Tik in het lege vak, houd ingedrukt en kies Plak.
  3. Tik op Run. Je ziet dan Success. No rows returned.
Doe dit maar één keer. Zie je een melding met already exists? Dan is de database al ingericht.

2 Inlogmail met code

Ga in Supabase naar Authentication → Emails (of Email Templates). Doe het volgende bij Magic Link én bij Confirm signup:

  1. en plak het bij Subject.
  2. , maak het vak Message body leeg en plak het erin.
  3. Tik op Save.

3 Sleutel doorgeven

  1. Ga naar Project Settings → API Keys.
  2. Kopieer de Publishable key (begint met sb_publishable_) en stuur die naar Claude.
De Secret key (begint met sb_secret_) deel je nooit, met niemand.

4 Agenda-koppeling

Hiermee kan iedereen zijn beurten en de vergaderingen in de agenda van zijn telefoon zetten.

  1. , ga naar SQL Editor → New query, plak en tik op Run.
  2. Ga naar Edge Functions en kies Deploy a new function → Via Editor.
  3. , maak het vak met code helemaal leeg en plak het erin.
  4. Noem de functie precies agenda en tik op Deploy function.
  5. Open de functie, ga naar Details of Settings en zet Verify JWT (of Enforce JWT verification) uit. Tik op Save. Een agenda-app kan namelijk niet inloggen; de persoonlijke link in de app beschermt de gegevens.
